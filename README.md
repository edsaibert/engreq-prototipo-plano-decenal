# engreq-prototipo-plano-decenal
Trabalho final de engenharia de requisitos

Nome do projeto: Sistema de Monitoramento de Compromissos Decenais da Criança e do Adolescente

Integrantes do grupo:
- Alexander Danila Mion
- Mayara Lessnau de Figueiredo Neves
- Eduarda Saibert

Descrição resumida do sistema: 

O sistema deverá permitir o acompanhamento de problemas públicos, compromissos, objetivos, linhas de ação, tarefas e indicadores, incluindo funcionalidades de busca, filtros, controle de usuários, exportação de dados, histórico de alterações e visualização de progresso.

Link do protótipo navegável: Apenas clicar em qualquer arquivo .html de @telas/

Organização das pastas: 
- docs/: contém todos os arquivos .md necessários, backlog.md, casos-uuso.md, historias-usuario.md, historico-versoes.md, matriz-rastreabilidade.md, regras-negocio.md, requisitos.md e visao-geral.md
- entregas/: contém os 4 arquivos com as entregas semanais, sendo um resumo do que foi feito semana a semana

Instruções para acessar a documentação:
Abrir o git em: https://github.com/edsaibert/engreq-prototipo-plano-decenal

Resumo das principais versões entregues:
- v0 (28/05): Estrutura inicial do projeto criada (boilerplate de pastas).
- v1 (30/05): Levantamento e revisão dos requisitos, definição do escopo e dos atores do sistema, além da documentação das inconsistências encontradas junto ao cliente.
- v2 (18/06): Refinamento de requisitos para maior clareza, criação da matriz de rastreabilidade inicial, definição da identidade visual e implementação das primeiras telas (login e gerenciamento de usuários).
- v3 (21/06): Implementação de todas as telas do protótipo, revisão da documentação e construção parcial da matriz de rastreabilidade.
- v4 (25/06): Finalização do protótipo com navegabilidade entre telas, padronização visual, recursos de acessibilidade (alto contraste) e conclusão da matriz de rastreabilidade relacionando requisitos e telas.
